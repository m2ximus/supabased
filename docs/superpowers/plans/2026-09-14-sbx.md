# sbx Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A bash CLI `sbx` that stores many Supabase access tokens in the macOS Keychain and runs `supabase` with the right account for the current folder.

**Architecture:** One script `bin/sbx` (bash 3.2) with subcommands. A zsh function `supabase(){ sbx exec -- supabase "$@"; }` emitted by `sbx init zsh`. Resolution walks up from the directory looking for `.sbx` pins or `supabase/.temp/project-ref`, mapping refs to accounts via a cache or the Management API.

**Tech Stack:** bash 3.2, macOS `security`, `curl` 8.x, `jq` (/usr/bin/jq), pure-bash tests.

**Spec:** `docs/superpowers/specs/2026-09-14-sbx-design.md` (read it — security reqs S1–S8 apply to every task).

## Global Constraints
- `#!/bin/bash`, `set -euo pipefail`, `umask 077`; bash 3.2 compatible (no `declare -A`, `mapfile`, `${x,,}`, `|&`).
- Tokens NEVER in argv, files, stdout, or error messages (S1, S2, S8).
- `SBX_HOME` (default `~/.config/sbx`) may be overridden. `SBX_API` is hardcoded to `https://api.supabase.com` and `SBX_SERVICE` to `sbx-supabase`; env overrides of these two are honoured ONLY when `SBX_TEST=1` (prevents a repo's direnv/.envrc from redirecting tokens to another host). Validate `SBX_SERVICE` against the name regex.
- Use the variable form for regexes: `re='^...$'; [[ $s =~ $re ]]`.
- In tests, build tab-containing expectations with `printf 'a\tb'`, never literal tabs.
- Regexes: name `^[a-z0-9][a-z0-9_-]{0,31}$`, ref `^[a-z0-9]{20}$`, token `^sbp_[A-Za-z0-9_]{20,}$`.
- Files in `$SBX_HOME`: `accounts` (one name per line), `default` (one name), `ref-cache` (`<ref> <name>` lines).
- Errors: `sbx: <message>` on stderr, exit 1. Commit after each task on branch `feat/sbx-v1`. Do not push.

### Task 1: Scaffold, test harness, stubs, helpers

**Files:**
- Create: `bin/sbx`, `tests/run.sh`, `tests/stubs/security`, `tests/stubs/curl`, `README.md`

**Interfaces — Produces (in `bin/sbx`):**
- `die MSG` → prints `sbx: MSG` to stderr, exit 1
- `valid_name S`, `valid_ref S`, `valid_token S` → exit status 0/1
- `ensure_home` → `mkdir -p "$SBX_HOME" && chmod 700 "$SBX_HOME"`
- `main "$@"` dispatch via `case`; `help` prints usage; unknown command → die.
- Script ends with `main "$@"` guarded so tests can also just invoke the binary (tests call the binary, not source it).

**Test harness (`tests/run.sh`):** each test is a function `t_*`; runner discovers with `declare -F | awk '{print $3}' | grep '^t_'`, runs each in a subshell with a fresh temp env:
```bash
setup() {
  T=$(mktemp -d); export SBX_HOME="$T/home" STUB_KC="$T/kc" STUB_API="$T/api" STUB_ARGV_LOG="$T/argv.log"
  mkdir -p "$STUB_KC" "$STUB_API"
  export PATH="$ROOT/tests/stubs:$PATH" SBX_SERVICE=sbx-test SBX_TEST=1 SBX_API=https://api.test
  SBX="$ROOT/bin/sbx"; cd "$T"   # isolate from stray .sbx/project-ref above the repo
}
assert_eq() { [ "$1" = "$2" ] || { echo "  expected [$2] got [$1]"; return 1; }; }
assert_contains() { case "$1" in *"$2"*) ;; *) echo "  [$1] lacks [$2]"; return 1;; esac; }
```
Print `PASS t_name` / `FAIL t_name`, exit non-zero if any fail.

**Stub `security`** (records every argv line to `$STUB_ARGV_LOG`):
- `security -i`: read stdin lines; for `add-generic-password -U -s SVC -a NAME -w TOKEN` write TOKEN to `$STUB_KC/$SVC.$NAME`.
- `security find-generic-password -s SVC -a NAME -w`: cat file or exit 44.
- `security delete-generic-password -s SVC -a NAME`: rm file or exit 44.

**Stub `curl`** (records argv to `$STUB_ARGV_LOG`): reads stdin header line `Authorization: Bearer TOKEN`; last arg is URL; if URL ends `/v1/projects` and `$STUB_API/TOKEN.json` exists, cat it, else exit 22.

### Task 2: Account store (add / remove / list / default)

**Interfaces — Produces:**
- `kc_set NAME TOKEN` → `printf 'add-generic-password -U -s %s -a %s -w %s\n' "$SBX_SERVICE" "$1" "$2" | security -i >/dev/null` (only after name+token validated — S1, S5)
- `kc_get NAME` → `security find-generic-password -s "$SBX_SERVICE" -a "$1" -w` (stdout = token; caller captures, never echoes)
- `kc_del NAME`
- `api_projects TOKEN` → `printf 'Authorization: Bearer %s\n' "$1" | curl -fsS --proto =https --max-time 15 -H @- "$SBX_API/v1/projects"` (JSON stdout)
- `has_account NAME`, `account_names` (reads `accounts`)
- Commands:
  - `sbx add NAME`: validate name; refuse args after name (never accept token arg); read token (`read -rs` from `/dev/tty` with prompt to stderr if stdin is a tty, else `read -r` from stdin); validate token; `api_projects` must succeed ("token rejected by Supabase API" on failure); `kc_set`; append name if new; if no default, set it. Print `added NAME (N projects)`.
  - `sbx remove NAME`: kc_del, remove from accounts/default/ref-cache lines ending ` NAME`.
  - `sbx list`: each name, `*` suffix on default. `--projects`: under each, `  <id>  <name>` from `jq -r '.[] | "  \(.id)  \(.name)"'`.
  - `sbx default NAME`: must exist.

### Task 3: Resolver (which / pin / refresh)

**Interfaces — Produces:**
- `resolve DIR` → prints `NAME<TAB>SOURCE<TAB>REF` and returns 0, or returns 1 with nothing printed. SOURCE ∈ `pin:<path>`, `ref`, `default`. REF is `-` if none.
  - Walk `d=DIR` up to `/`: if `$d/.sbx` exists → first line trimmed; if `valid_name` and `has_account` → hit; else warn `sbx: ignoring .sbx at $d (unknown account)` to stderr and continue walking. Else if `$d/supabase/.temp/project-ref` exists and `valid_ref` → `ref_owner REF`; if found → hit; else warn `sbx: no saved account owns project REF` and break to default.
  - Fallback: default file if `has_account`.
- `ref_owner REF` → cache grep `^REF ` (verify name still `has_account`); else for each account: `kc_get` → `api_projects` → `jq -e --arg r "$REF" 'any(.[]; .id==$r)'`; on hit append `REF NAME` to ref-cache. API failures for one account are skipped silently.
- Commands: `sbx which [DIR]` (prints resolve output; exit 1 + stderr `sbx: no account for DIR` if none); `sbx pin NAME` (must exist; writes `$PWD/.sbx`, mode 644 is fine since not secret — use `umask 022` subshell); `sbx refresh` (rm ref-cache).

### Task 4: exec, status, init zsh

**Interfaces — Produces:**
- `sbx exec -- CMD [ARGS...]`:
  - If `SUPABASE_ACCESS_TOKEN` already set and non-empty → `exec "$@"` unchanged.
  - Else `resolve "$PWD"`; on hit: `tok=$(kc_get NAME)` (fail → die `keychain lookup failed for NAME`), `SUPABASE_ACCESS_TOKEN="$tok" exec "$@"` (env var, not argv — S1/S3).
  - On miss: stderr `sbx: no account for this folder; using supabase's own login`, `exec "$@"`.
  - If `SBX_QUIET` unset, print one stderr line `sbx → NAME (SOURCE)` before exec.
- `sbx status`: `account: NAME`, `source: SOURCE`, `project: REF` (or `no account for this folder`). Never prints token.
- `sbx init zsh`: prints exactly:
  ```zsh
  supabase() { command sbx exec -- supabase "$@"; }
  ```
  Plus comment line `# sbx: per-folder Supabase accounts`.

**Tests:**
```bash
t_exec_injects_token_into_child_only() {
  add work ...; mkdir "$T/p"; cd "$T/p"

}
t_exec_respects_explicit_env() { add work; out=$(SUPABASE_ACCESS_TOKEN=sbp_explicit SBX_QUIET=1 $SBX exec -- sh -c 'printf %s "$SUPABASE_ACCESS_TOKEN"'); assert_eq "$out" sbp_explicit; }
t_exec_no_account_runs_untouched() { mkdir "$T/p"; cd "$T/p"; out=$($SBX exec -- sh -c 'printf %s "${SUPABASE_ACCESS_TOKEN:-none}"' 2>/dev/null); assert_eq "$out" none; }
```
